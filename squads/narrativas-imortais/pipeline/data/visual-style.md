# Guia Visual — Narrativas Imortais

## Estilo das Imagens

### Conceito Visual do Canal
As imagens do canal Narrativas Imortais evocam a estética das grandes ilustrações literárias do século XIX — especialmente as gravuras de Gustave Doré para Dante, Milton e Cervantes. Atmosféricas, detalhadas e com iluminação dramática, as imagens transportam o espectador para o mundo da obra sendo narrada.

### Paleta Obrigatória
- Predominância de tons escuros: pretos profundos, marrons escuros, grafite
- Destaques dourados/âmbar: `#C9A02A` — luz de vela, momentos de revelação
- Ocre/pergaminho: `#8B6914` — textura de livro antigo, aquecimento
- Cinza azulado: `#4A5568` — névoa, profundidade, mistério
- Nunca cores saturadas pop ou cores de design moderno

### Estilos Base por Gênero

**Literatura Clássica Europeia (Poe, Kafka, Dostoiévski, Wilde...):**
```
detailed engraving illustration style inspired by Gustave Doré, dramatic ink crosshatching, candlelight or moonlight illumination, dark Victorian atmosphere, aged paper texture undertones
```

**Literatura de Horror / Gótica (Lovecraft, Shelley, Stoker...):**
```
gothic horror illustration, deep shadows with minimal cold blue light, fog and darkness, otherworldly atmosphere, detailed ink work, Romanticism-era painting style
```

**Filosofia Clássica (Nietzsche, Schopenhauer, Camus...):**
```
classical oil painting style, dramatic chiaroscuro, solitary figure in vast landscape, existential emptiness, muted earth tones with single warm light source, contemplative atmosphere
```

**Literatura Russa (Tolstói, Turguêniev, Gógol...):**
```
Russian realist painting style, cold winter light or warm indoor candlelight, dense atmospheric detail, faces full of emotion, vast steppes or intimate interiors, 19th century setting
```

**Literatura Filosófica Francesa (Camus, Sartre, Beauvoir...):**
```
mid-century illustration, muted palette, existential solitude, urban Parisian setting or Mediterranean light, melancholic atmosphere, slightly desaturated tones
```

### Composição
- Personagem ou elemento central sempre em destaque (centro ou primeiro plano)
- Cenário evocativo ao fundo (biblioteca, floresta sombria, cidade antiga, horizonte vasto)
- Iluminação dramática: chiaroscuro (luz forte de uma única fonte + sombra profunda)
- Ângulo levemente de baixo para cima OU ponto de vista envolvente — transmite profundidade

## Notas Técnicas
- Formato de saída: JPG, landscape 16:9
- Resolução: 1280×720 (test) ou 1920×1080 (produção)
- **Nunca incluir texto nas imagens geradas** — IA lida mal com letras; títulos são adicionados no editor
- **Nunca usar cores saturadas modernas** — manter sempre a paleta histórica/atmosférica
- Modo test para aprovação → modo produção para entrega final
